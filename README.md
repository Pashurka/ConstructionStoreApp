
# ConstructionStoreApp
**ConstructionStoreApp** — мобільний застосунок для магазину будівельних матеріалів, призначений для автоматизації процесу онлайн-покупок через Android-пристрої. Програмний продукт забезпечує доступ до каталогу товарів, пошук продукції та оформлення замовлень.

## Мета проєкту
Метою розробки є створення зручного та безпечного мобільного інструменту для онлайн-покупок будівельних матеріалів, автоматизації основних бізнес-процесів магазину та покращення взаємодії з клієнтами.
Особлива увага приділяється стабільності роботи, зручності пошуку товарів, захисту даних і підтримці сценаріїв роздрібних та оптових покупок.

## Основні можливості
- Перегляд каталогу будівельних матеріалів.
- Пошук і фільтрація товарів.
- Перегляд інформації про продукцію.
- Оформлення замовлень.
- Підтримка сценаріїв обслуговування роздрібних та оптових покупців.
- Автентифікація користувачів.
- Захист і шифрування даних.
- Інтеграція з платіжними системами.

## Технології
| Технологія | Призначення |
|---|---|
| C# | Основна мова програмування |
| .NET | Платформа розробки |
| Xamarin | Кросплатформна мобільна розробка |
| MVVM | Розділення інтерфейсу та логіки застосунку |
| Clean Architecture | Організація архітектури програмного продукту |
| OAuth 2.0 | Механізм авторизації |
| NUnit | Модульне тестування |
| Xamarin.UITest | Автоматизоване тестування інтерфейсу |

## Архітектура
В основі програмного продукту лежать принципи **MVVM (Model–View–ViewModel)** та **Clean Architecture**.
MVVM забезпечує розділення представлення, стану інтерфейсу та логіки взаємодії з даними. Clean Architecture сприяє незалежності основних компонентів системи від конкретних технологій реалізації.

## Безпека
Для підвищення рівня захисту застосунку передбачено:
- автентифікацію користувачів із використанням OAuth 2.0;
- захист інформації під час взаємодії компонентів системи.

## Тестування
Для перевірки якості програмного продукту використовувалися:
- **NUnit** — для модульного тестування;
- **Xamarin.UITest** — для автоматизованого тестування користувацького інтерфейсу.
Тестування було спрямоване на перевірку коректності основних сценаріїв роботи, стабільності та ефективності застосунку.

## Запуск проєкту
Для відкриття та запуску ConstructionStoreApp необхідні:
- Visual Studio з підтримкою Xamarin;
- відповідний .NET Framework або Xamarin SDK;
- Android SDK та налаштоване середовище емуляції або фізичний Android-пристрій;
- необхідні конфігураційні параметри зовнішніх сервісів, якщо вони використовуються.
Клонуйте репозиторій:
```bash
git clone https://github.com/Pashurka/ConstructionStoreApp.git
```
Відкрийте solution-файл у Visual Studio, відновіть NuGet-пакети та налаштуйте цільове середовище запуску.
